# Paradigms: complete tables

Every Kaqchikel cell in this file was checked against the whole corpus (modern
textbooks, the Kik'aslemal sequel, the Oxlajuj Aj course, readers, the OKMA grammar, Bible
translations, social media, Wikipedia and Firefox localizations). A plain form occurs in at
least one source. A form with `†` was not found and is derived by the rule printed under its
table; it is regular but unwitnessed, so prefer an attested neighbour when you can. `[?]` means
the derivation itself is uncertain: do not use the form in confident output.

Glossing labels: Set A = ergative (transitive subject, possessor), Set B = absolutive
(intransitive subject, transitive object). Person labels: 1s = I, 2s = you (sg.), 3s = he/she/it,
1p = we, 2p = you (pl.), 3p = they. Aspects: INC = incompletive (present, habitual, near
future), COMPL = completive (past), POT = potential (future), IMP = imperative/hortative.

Spelling: ALMG, straight apostrophe for the glottal stop. Lax vowels (ä ë ï ö ü) stand only in a
word's last syllable; when a suffix is added they become tense (löq' "buy" but taloq'o' "buy
it!"). Dialects and the two Maxwell-team books differ on several cells; those are flagged with
both forms. See grammar.md for the rules behind each table.

### 1. The two person-marker sets

| person | free pronoun | Set B (absolutive) before C / V | Set A on verbs before C / V | Set A on nouns before C / V |
|---|---|---|---|---|
| 1s | rïn / rin | i- / in- | in- / inw- | nu- / w- |
| 2s | rat | a- / at- | a- / aw- | a- / aw- |
| 3s | rija' | zero | u- (ru-) / r- | ru- / r- |
| 1p | röj | oj- / oj- | qa- / q- | qa- / q- |
| 2p | rïx / rix | ix- / ix- | i- / iw- | i- / iw- |
| 3p | rije' | e- / e'- | ki- / k- | ki- / k- |

Free pronouns: the sequel writes rïn, rïx (lax); the 2006 course and most modern schoolbooks write rin, rix. With a noun or adjective predicate, Set B is a separate word before it: ïn (in), at, (zero), öj, ïx, e. On verbs the 3s Set A is u- right after an aspect prefix (x-u-, n-u-, xt-u-) and ru- after a Set B prefix (x-e-ru-, x-oj-ru-). Only 1s differs between verb and noun: in-/inw- on verbs, nu-/w- on nouns, relational nouns and perfects. Before a consonant, Set B 1s in- and 2s at- usually lose their final consonant (xib'e, xab'e): this is what the courses teach and what most texts write (xib'e 47 tokens vs xinb'e 0; xkib'e 40 vs xkinb'e 1). Keeping in-/at- before a consonant (xatb'e, yatb'e, xinwa') is a minority, regional form found in the OKMA grammar and some school readers.

### 2. Aspect and mood prefixes

| aspect | before 3s (zero) Set B | before any other Set B | example |
|---|---|---|---|
| INC | n- (ni- before a consonant in many towns) | y- | nb'e / nib'e / yib'e |
| COMPL | x- | x- | xb'e / xib'e |
| POT | xt- (xti- before a consonant) | xk- | xtib'e / xkib'e |
| IMP intransitive | t- (ti- before a consonant) | k- | tib'e / kab'e |
| IMP transitive | t- | k- (kin-, koj-, ...) | tab'ana' / tub'ana' / kinato' |

Choose by the Set B slot, whatever its role: y- if it is filled (1s, 2s, 1p, 2p, 3p), n- if it is the empty 3s. The potential works the same way with xt- / xk-. Some sequel-era writers drop the i of ni- (nb'e, nsamäj).

The incorporating antipassive keeps a bare object after the verb: nikemon po't 'she weaves po't (a po't-weaver)', and makes compound agent nouns with -oy: kemoy po't (Kik'aslemal pp. 225-226).

| term | término | plain meaning |
|---|---|---|
| absolutive (Set B) | absolutivo (Juego B) | marks who undergoes a transitive action, the single participant of an intransitive verb, and what a non-verbal predicate is about: in-/at-/zero/oj-/ix-/e- |
| ergative (Set A) | ergativo (Juego A) | marks the doer of a transitive action and the owner of a noun: nu-/in-, a-, ru-/u-, qa-, i-, ki- |
| aspect | aspecto | how an event is viewed (finished, ongoing, projected); Kaqchikel marks aspect, not tense |
| incompletive | incompletivo | n-/y-: present, habitual, ongoing, near future |
| completive | completivo | x-: completed event, usually past |
| potential | potencial | xt-/xk-: projected or future event |
| imperative / hortative | imperativo / exhortativo | t-/k-: commands, wishes, "let's", "may he" |
| perfect, participle | perfecto, participio | -näq (intransitive) / -on (transitive): a resulting state, "has gone", "has seen", with no time of its own |
| root transitive | transitivo radical | one-syllable CVC transitive root (-löq', -tz'ët, -b'än); lax vowel; -V' in the imperative |
| derived transitive | transitivo derivado | transitive stem ending in -Vj (-tz'ib'aj, -k'utuj, -oyob'ej) |
| intransitive | intransitivo | verb with only a subject (Set B) |
| passive | voz pasiva | intransitive with the patient as subject; agent optional with roma/ruma |
| antipassive | voz antipasiva | intransitive with the agent as subject; object omitted, with richin, or bare |
| focus antipassive | antipasiva de enfoque | the antipassive used when the agent is questioned or clefted ("who did it?", "it was X who...") |
| middle voice | voz media | -(i)täj: something "got done" with no agent implied |
| causative | causativo | -(i)sa(j)/-esaj: "make someone do": -wartisaj 'put to sleep', -elesaj 'take out' |
| reflexive | reflexivo | object expressed by the relational noun -i': xusök ri' 'she cut herself' |

| positional | posicional (k'ojlemal) | root naming a body position or shape (tz'uy sit, pa' stand) with its own family of derivations |
| relational noun | sustantivo relacional | possessed noun doing the job of a preposition: ruk'in 'with her', chuwäch 'in front of it' |
| possessive class | clase de sustantivo (por posesión) | how a noun changes when possessed (no change, vowel tensing, losing -aj/-ej, adding -il) |
| lax / tense vowel | vocal relajada / tensa | ä ë ï ö ü (lax) vs a e i o u (tense); lax only in final syllables |
